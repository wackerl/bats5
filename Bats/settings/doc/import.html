Import of data

NEC files

NEC files in the file format as used in Lund (Sweden) can be opend (without editing cycles). Setting for import can be modified and are stored in the file: Settings/C14/file_io/nec.xml

 

HV files

HV files in the file format as used in Seville (Spain) can be opend (without editing cycles). Setting for import can be modified and are stored in the file: Settings/C14/file_io/hv.xml
